Les méthodes « concentration » ou « attaque » renvoient une promesses
La méthode « jouerTour » utilise les promesses

Il est possible de tester les méthodes depuis la console avec le code suivant : 


const r1 = concentration(5_000);
const r2 = attaque();
jouerTour('Della');
jouerTour('Zaza');
